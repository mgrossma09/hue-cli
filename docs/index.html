huectl

Fast, scriptable Philips Hue CLI (Hue API v2)

Automate lights with a clean command-line interface built for shell scripts and quick terminal workflows. Works on macOS and Linux with explicit bridge configuration.

Install GitHub

Features

Hue API v2

Built for modern Philips Hue API v2 endpoints with practical defaults.

Script-Friendly CSV

Quick parsing and automation with CSV output modes for shell pipelines.

Explicit Config

No bridge discovery required. Set host and token via env vars or config file.

Cross-Platform

Prebuilt binaries for macOS and Linux on amd64 and arm64.

Examples

Terminal-style command examples.

lights list --csv

$ huectl lights list --csv
id,name,on
18a1-...,Kitchen,true
2f3b-...,Office,false

lights toggle --group

$ huectl lights toggle --group Kitchen
toggled 3 light(s) in group Kitchen

Install

Homebrew

brew tap mgrossma09/tap
brew install huectl

install.sh

curl -fL -o install.sh \
  https://raw.githubusercontent.com/mgrossma09/hue-cli/main/install.sh
bash install.sh

Quickstart

export HUE_BRIDGE_HOST=192.168.1.2
export HUE_API_TOKEN=your-hue-token

huectl lights list --csv
huectl lights toggle --id 01234567-89ab-cdef-0123-456789abcdef
