# Enable GitHub Pages for huectl

Configure Pages to serve from the `docs/` directory on `main`:

1. Open repository settings on GitHub.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**.
5. Select folder **/docs**.
6. Save.

Site URL pattern:

- `https://mgrossma09.github.io/hue-cli/`
